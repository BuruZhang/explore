# 创作方向 v0.1

## 核心目标

将参考作品中的视觉关系转译为可控制的设计，再以独立内容完成有用途、有主体、有观看顺序的画面。

## 五项执行原则

1. **简报先行。** 明确用途、受众、希望传达的信息、画幅与投放尺寸。探索性艺术也需定义情绪和观看体验。
2. **参考职责明确。** 每张图注明取用维度。材质图负责表面与光学表现；构图图负责机位、透视、占比和空间；叙事图负责动作关系与事件组织。取用结果需在新内容上重新设计。
3. **结构先定。** 先核对轮廓、主次、明暗、前中后景与动线，再丰富颜色和材质。选定母版后维护其机位与主体比例。
4. **细节有分配。** 用大形、中形、小形建立秩序；将主要细节放在焦点，背景降低纹理和高光密度。光滑、粗糙、透光和毛绒的对比服务主题。
5. **交付靠验收。** 逐项对照简报和参考证据，局部修正后完成排版、裁切与导出。工作流 v0.1 需通过实际项目验证。

## 参考蒸馏的证据标准

每个结论必须包含：参考局部位置、可见特征、在新画面中的落点、验收方法。

例如“半透明材质”应落成：薄边在逆光处透光，厚处更实，暗部保留体积；通过边缘和重叠区域检查。单凭成图无法确认的材质参数、实际焦距与制作软件标为推测。

## 内容设计标准

一句话写出主体、动作、对象和可见结果。抽象场景可用变化、运动趋势、空间关系或情绪冲突构成事件；静态视觉也可通过稳定的形态秩序表达主题。

用户指定的主体形成单独设定卡，并在系列中保持身份。羽毛笔只是特定项目的主体选择；自然背景、未来感等约束按项目简报确定。

## 提示词组织

按“输入职责→本轮目标→母版保持项→主体和动作→空间与机位→光影色彩→材质及细节预算→必要排除项”书写。每轮聚焦一个主要问题；用短而明确的指令表达变化。
