# 视觉设计方法笔记

## 设计与执行

| 主题 | 方法 | 执行产物 |
| --- | --- | --- |
| 需求 | 明确设计对象、受众、传播目的和投放场景 | 项目简报 |
| 制作阶段 | 创意主题、图像制作、后期包装分阶段完成 | 分阶段母版 |
| 画面诊断 | 用主体大小、密度、方向和前后关系判断可读性 | 缩略图与灰度验收 |
| 构图 | 框式、对角线、向心、对分、三角和 S 形组织不同视线关系 | 构图骨架 |
| 空间 | 透视、尺寸、明度、纯度与冷暖共同建立距离 | 前中后景关系表 |
| 节奏 | 以曲线、放射或连续元素关系设置观看顺序 | 视觉入口与焦点 |
| 多主体 | 沿动线安排大小与前后距离，环境和道具共同承担支点 | 主次元素层级 |
| 主体设定 | 通过轮廓、体型、动作与表情建立辨识度 | 主体母版 |
| 输入分工 | 参考、内容、机位和材质分别定义职责 | 输入映射表 |
| 视觉清理 | 轮廓和大色块优先，细节集中于焦点 | 细节密度检查 |
| 材质转换 | 保留设定识别点，分区控制表面和光学表现 | 材质样张 |
| 场景修改 | 锁定结构和透视，分别处理内容、光线与局部细节 | 编辑母版 |
| 系列设计 | 固定主体识别、色彩与版式，变化场景和动作 | 系列规范 |
| 动态设计 | 建立起止状态和分镜，分别检查镜头与物体运动 | 动作分镜 |
| 交付 | 根据真实项目定义数量、尺寸、格式和包装 | 交付清单 |

## 图像判断

主体在缩略图中清晰可辨；其他元素通过大小、位置、对比和密度支持焦点。路径保持连续，前中后景有遮挡与尺度差异。

灰度检查用于确认明暗层级。具体画面的亮度、清晰度和饱和度分配由光源及叙事决定。

系列识别由稳定的造型、色块和版式建立，场景、动作及机位按内容变化。

## 应用条件

画风、头身比、材质、焦距和机位按项目目的选择。表面清理针对纹理密度、反射分布和噪声；导出尺寸由使用场景决定。执行前核对工具实际能力。

## 后续验证

- 用实际项目验证各阶段输入与锁定范围。
- 检查动态分支的主体一致性、空间和时序。
- 按构图、色彩、材质及排版用途建立参考索引。
- 对每次迭代保存证据、问题和验收结果。
